# DocsLite

A distributed real-time collaborative document editor.

## Technology Stack

### Frontend
- React
- TypeScript
- Vite
- TipTap
- Yjs

### Backend
- Node.js
- TypeScript
- Fastify
- WebSockets

### Database and Infrastructure
- PostgreSQL
- Redis
- Docker
- Nginx

### Monitoring
- Prometheus
- Grafana

## Project Goals

- Real-time collaborative editing
- Conflict-free synchronization using CRDT
- Horizontal WebSocket scaling
- Durable document persistence
- Offline editing
- Fault tolerance
- 10,000+ concurrent connection scalability target
